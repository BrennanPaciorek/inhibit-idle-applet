# Inhibit Idle Applet

An inhibit idle applet for COSMIC™ desktop

Uses the [org.freedesktop.ScreenSaver](https://specifications.freedesktop.org/idle-inhibit/latest/) dbus API to inhibit idle behavior.

To use it, install via the just commands, then add the applet to your panel in the COSMIC™ settings application.

This applet was created via heavy modification of the initial project generated by the [cosmic-applet-template](https://github.com/pop-os/cosmic-applet-template).

## Using the applet

The applet places a lock icon on your screen, indicating it idle locking is not being inhibited.

Clicking on the applet icon crosses this lock out, indicating that the applet is inhibiting idle behavior.

## Installation

A [justfile](./justfile) is included by default for the [casey/just][just] command runner.

- `just` builds the application with the default `just build-release` recipe
- `just run` builds and runs the application
- `just install` installs the project into the system
- `just vendor` creates a vendored tarball
- `just build-vendored` compiles with vendored dependencies from that tarball
- `just check` runs clippy on the project to check for linter warnings
- `just check-json` can be used by IDEs that support LSP

## Translators

[Fluent][fluent] is used for localization of the software. Fluent's translation files are found in the [i18n directory](./i18n). New translations may copy the [English (en) localization](./i18n/en) of the project, rename `en` to the desired [ISO 639-1 language code][iso-codes], and then translations can be provided for each [message identifier][fluent-guide]. If no translation is necessary, the message may be omitted.

## Packaging

If packaging for a Linux distribution, vendor dependencies locally with the `vendor` rule, and build with the vendored sources using the `build-vendored` rule. When installing files, use the `rootdir` and `prefix` variables to change installation paths.

```sh
just vendor
just build-vendored
just rootdir=debian/inhibit-idle-applet prefix=/usr install
```

It is recommended to build a source tarball with the vendored dependencies, which can typically be done by running `just vendor` on the host system before it enters the build environment.
